# 🏆 競賽評分系統 — 使用說明

一個給評審打分數的網頁，送出後資料會自動寫進 Google 試算表，方便統計。

**評分項目：** 創意性 (0-10)、技術性 (0-10)、BUG 尋找力 (0-10)、意見
**規模：** 9 位參賽者、10 多位評審

---

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 評審用的評分網頁（自行修改名單） |
| `apps-script/Code.gs` | Google Apps Script 後端程式 |

---

## 設定步驟

### 第 1 步：建立 Google 試算表

1. 到 [Google 試算表](https://sheets.google.com) 建立一個新試算表，例如命名「競賽評分」。
2. 不用手動加標題，程式第一次寫入時會自動建立「評分紀錄」分頁與標題列。

### 第 2 步：貼上後端程式並部署

1. 在試算表上方選單點 **擴充功能 → Apps Script**。
2. 把預設的 `Code.gs` 內容全部刪掉，貼上本專案 `apps-script/Code.gs` 的內容。
3. 點右上角 **儲存**（磁碟圖示）。
4. 點右上角 **部署 → 新增部署作業**。
5. 類型選 **網頁應用程式 (Web app)**。
6. 設定：
   - **執行身分**：我（你的帳號）
   - **誰可以存取**：**所有人 (Anyone)** ← 一定要選這個，評審才連得上
7. 點 **部署**，第一次會要求授權，依指示允許（若出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往…（不安全）→ 允許**，這是你自己的程式，安全）。
8. 複製產生的 **網頁應用程式網址**（結尾是 `/exec`）。

### 第 3 步：把網址填進網頁

打開 `index.html`，找到最上方的設定區，修改這三處：

```js
// 1) 貼上剛剛複製的 Apps Script 網址
const SCRIPT_URL = "https://script.google.com/macros/s/xxxxx/exec";

// 2) 改成你們真正的 9 位參賽者名字
const CONTESTANTS = ["王小明", "李小華", ...];

// 3) 改成你們真正的評審名字
const JUDGES = ["張評審", "陳評審", ...];
```

### 第 4 步：發給評審使用

有幾種方式讓評審打開網頁：

- **最簡單**：把 `index.html` 直接寄給評審，他們用瀏覽器打開即可（電腦或手機皆可）。
- **統一連結（推薦）**：把 `index.html` 放到免費的靜態網站空間，例如 [Netlify Drop](https://app.netlify.com/drop)（直接把檔案拖進去就有網址）或 GitHub Pages，然後把網址發給所有評審。

## 統計資料

所有評分都會即時進到試算表的「評分紀錄」分頁，欄位為：

`接收時間 | 評審 | 參賽者 | 創意性 | 技術性 | BUG尋找力 | 總分 | 意見`

你可以另開一個分頁用樞紐分析表（插入 → 樞紐分析表）或以下公式做統計：

- **某參賽者的平均總分**：`=AVERAGEIF(評分紀錄!C:C, "王小明", 評分紀錄!G:G)`
- **各參賽者總分排名**：用樞紐分析表，列＝參賽者，值＝總分（平均）。

## 常見問題

- **送出後試算表沒資料？** 檢查 `SCRIPT_URL` 是否貼正確、部署時「誰可以存取」是否選「所有人」。
- **改了 Code.gs 後要重新部署嗎？** 要。到 Apps Script 點 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。
- **可以同時多位評審一起打嗎？** 可以，Apps Script 會依序寫入，不會互相覆蓋。
